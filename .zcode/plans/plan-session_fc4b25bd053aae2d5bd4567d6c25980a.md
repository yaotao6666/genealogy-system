# 智慧族谱 · H5 交互原型

## 产出物
一个**自包含的单文件 HTML 交互原型**（`prototype/index.html`，无外部依赖，双击即可打开），覆盖访客端与管理端全部核心流程。桌面浏览器打开时居中显示 390px 手机壳预览，手机访问时全屏。

## 原型页面清单（约 15 屏，全部可点击串联）

**访客端（未登录可浏览）**
1. **首页** — 谱馆门户：谱名封面、族人搜索框、功能入口（世系图 / 原谱阅览 / 族人名录）、修谱公告
2. **世系图浏览** — 纵向族树可视化，节点点击进入族人详情
3. **族人名录** — 按世代分组 + 搜索
4. **族人详情** — 结构化信息卡（名/字/号、世代、生卒、配偶、生平）、父子配偶子女关系（可点击跳转）、**关联原谱页缩略图**（点击直达原谱对应页）、"申请变更"入口
5. **原谱目录** — 卷册列表（卷一/卷二…），显示各卷页数与录入进度
6. **原谱翻书阅览** — **翻书翻页动画**（CSS 3D），目录抽屉按卷跳页，当前页下方展示"本页关联族人"标签（可点进详情）
7. **变更申请表单** — 选类型（新增/修改/纠正关联）→ 填内容 → 上传佐证图 → 提交成功提醒

**管理端（单管理员登录）**
8. **登录页** — 账号密码
9. **管理工作台** — 待办提醒卡（待审核 N 条 / 本周录入 N 页）、快捷入口、**适老化"大字模式"开关**
10. **拍照录入向导（4 步）** — ①拍照/相册选图（调起相机）→ ②选卷册页码（自动递增）→ ③录入本页族人信息 → ④勾选本页关联族人 → 完成提醒；带步骤进度条
11. **族人维护** — 列表搜索 + 新增/编辑表单（大字段、校验提醒）
12. **变更审核** — 待处理/已处理列表 → 详情（申请内容 vs 现有信息**对比视图**、佐证图）→ 通过/驳回（二次确认弹窗 + 驳回理由）
13. **原谱管理** — 卷/页管理，每页"已关联/未关联"状态标识，补拍/替换照片

## 设计要点
- **视觉**：中式雅致 — 宣纸米色底、朱砂/黛青点缀、衬线标题字、印章式元素
- **适老化**：大字号基准与宽松行距、大按钮大点击区、所有关键操作有确认弹窗、操作后明确成功/失败提醒、分步向导带进度指示、"大字模式"一键放大
- **原型数据**：内置一套示例谱数据（某氏宗谱、4 代族人、2 卷原谱页），全链路可走通
- **评审辅助**：悬浮"原型导航"面板，可快速跳转任意页面

## 实施步骤
1. 加载 visualize 技能获取内联渲染规范
2. 编写单文件 HTML 原型（结构 → 样式 → 交互 JS）
3. 保存至项目 `family_tree/prototype/index.html`，并复制一份到会话可视化目录供 ZCode 桌面内联预览
4. 浏览器走查全部流程，核对页面与交互完整性
