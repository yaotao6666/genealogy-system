# 智慧族谱（太原堂王氏 · 演示实现）

纸质族谱「逐页拍照 → OCR 识别 → 结构化录入 → 双向关联 → 公开浏览 → 变更申请审核」的完整可运行实现。
**零第三方依赖**：后端仅用 Python 标准库，前端为原生单页应用。

## 运行

```bash
cd app
python3 seed.py        # 生成演示数据（30 代 20000 人，固定随机种子，可重复执行）
python3 server.py      # 启动服务，默认 http://127.0.0.1:8787
```

浏览器打开 <http://127.0.0.1:8787>（手机同一局域网访问 `http://<本机IP>:8787` 自动全屏）。
大屏驾驶舱：<http://127.0.0.1:8787/screen>（祠堂/会议投屏，深色数据大屏）。

- 管理员账号：`admin / admin123`
- 访客无需登录：可浏览全部族谱、翻阅原谱、提交变更申请
- 管理员登录后：拍照录入（OCR）、族人维护、变更审核、原谱管理

## 核心功能说明

### 拍照识别（OCR 简化录入）
录入向导：①拍摄/选图 → ②选卷页（自动定位第一个未录入页）→ ③**自动识别**：
返回逐字段结构化结果与置信度，低置信字段标红提醒，多记录分页签逐条核对 → ④勾选保存，
自动与该谱页建立双向关联，并按「名字+上一世代」自动匹配父亲。

识别引擎在 `server.py::demo_ocr_engine`，当前为**演示引擎**：演示数据的「待整理残页」
内含真值记录，识别即还原该页内容（与真实 OCR 的调用契约完全一致）。接入生产引擎时
仅需替换该函数（百度 OCR / Tesseract / 视觉大模型均可），前端与接口不变。

### 大屏驾驶舱（/screen）
面向投屏展示的深色数据大屏，数据来自 `/api/screen` 聚合接口：
- **可折叠世系树**：拖动「展开至 N 世」滑杆按代数折叠层级，节点「▾N子」逐支展开/收起，
  点左侧「主要支系」排名可重定位树根（一键回到始祖）；支持全谱搜索定位族人。
- **族人明细**：点击树中任意人名，右侧展示结构化明细（生卒/字号/配偶/父亲/生平/关联原谱页）；
  点击左侧「世代人口」柱形可查看该世族人名录。
- **图表**：朝代分布、世代人口金字塔、主要支系后嗣排名、页面关联率环形图与协作进度。
- **说明介绍**：首屏自动展示谱馆缘起、智慧谱馆模式与驾驶舱用法，右上角可随时重看。

### 数据规模
30 代 20000 人（唐咸通年间始祖 → 清道光），12 卷 7161 页，252 条待录入真值，
父子世代关系、生卒纪年（年号格式化）均通过完整性校验。列表/搜索/树均为按需分页与懒加载，
2 万级关键词搜索约 7ms。

## 主要接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/info · /api/stats · /api/notices | 公开概览 |
| GET | /api/members?q&gen&page&size | 族人分页搜索 |
| GET | /api/members/<id> | 族人详情（父/子/关联页） |
| POST/PUT/DELETE | /api/members… | 族人维护（管理员） |
| GET | /api/tree/roots · /api/tree/children/<id> | 世系树懒加载 |
| GET | /api/volumes · /api/volumes/<id>/pages · /api/pages/<no> | 卷册与谱页 |
| GET | /api/screen | 大屏驾驶舱聚合（朝代分布/支系后嗣/进度） |
| GET | /api/pages/next-unlinked | 自动定位下一待录入页 |
| POST | /api/pages/<no>/recognize | 拍照识别（存照片+返回结构化结果） |
| POST | /api/pages/<no>/confirm | 确认录入（建人+建关联+消费真值） |
| POST | /api/requests | 提交变更申请（公开） |
| POST | /api/requests/<id>/approve · /reject | 审核（管理员） |

## 设计说明

- 界面沿用高保真原型的「中式雅致」视觉与全部适老化设定（大字号三档、大点击区、
  关键操作二次确认、操作结果提醒、分步向导）。
- 单管理员模型：写操作走 Bearer Token；变更申请是唯一的公开写入口，审核后才落库。
- 族人删除有保护：存在子女记录时拒绝删除。
