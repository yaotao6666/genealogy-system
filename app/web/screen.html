智慧族谱 · 谱馆介绍

谱馆缘起　太原堂王氏，唐咸通年间始迁祖王德明公自太原府避乱南迁，卜居桐川之阳，耕读传家，绵延三十世。光绪老谱一套十二卷，历经风雨，纸页脆黄。

智慧谱馆　本馆将纸质族谱逐页拍照归档，通过拍照识别（OCR）辅助录入结构化数据，实现「原谱页 ⇄ 族人信息」双向关联：在世系树中点击任意族人，即可查其明细并直达其所载原谱页；翻阅原谱时，亦可点看该页收录的族人。

众擎共修　族人访客无需登录即可浏览全部内容；发现讹误或缺漏，可在族人详情页提交变更申请，由谱馆管理员核对后生效，确保谱牒信实。

驾驶舱用法　中间为可折叠世系树：拖动「展开至 N 世」滑杆按代数折叠层级，点「▾N子」逐支展开，点支系排名可重定位树根；点击人名在右侧查看明细；左侧图表点击柱形可查看该世族人名录。

演示环境：数据由生成器构造（30 代 20000 人），管理员账号 admin / admin123；识别引擎为可插拔演示实现，生产环境可接入真实 OCR / 视觉大模型。
